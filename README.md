# Autonomous Sumobot

## Overview
Designed and built an autonomous robot for a robotics competition using Arduino and ultrasonic sensors. The robot detects opponents and navigates the arena using sensor-driven control logic.

## Features
- Real-time motor control
- Ultrasonic-based opponent detection
- Autonomous navigation and decision-making

## My Contributions
- Implemented control logic for movement and opponent detection
- Integrated sensors and motor drivers
- Debugged hardware and firmware under competition conditions

## Tech Stack
Arduino (C/C++), ultrasonic sensors, motor drivers

## Outcome
Achieved 2nd place in a competitive robotics tournament
